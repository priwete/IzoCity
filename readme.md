# ИЗО-СИТИ (Iso-City)
Изометрический градостроительный симулятор в стиле классических SimCity, написанный на чистом HTML/CSS/JavaScript с использованием Canvas API. Никаких игровых движков, npm, сборщиков или внешних ассетов.

## 🎮 Управление

**Мышь:**
* **Клик по клетке** — применить выбранный инструмент (построить, покрасить, снести).
* **Перетаскивание левой кнопкой** — панорамирование камеры.
* **Колесо мыши** — зум (от 0.5× до 2.5×).
* **Наведение** — подсветка клетки (зелёная, если строить можно; красная, если нельзя).

**Клавиатура:**
* **WASD / Стрелки** — панорамирование камеры.
* **1** — Жилая зона (R)
* **2** — Коммерческая зона (C)
* **3** — Промышленная зона (I)
* **4** — Дорога
* **5** — Снос (бульдозер)
* **P / Esc** — Пауза (открывает мини-меню).
* **Esc** — если выбран инструмент, сначала сбрасывает его.

**Мобильные устройства (Тач):**
* **Тап по клетке** — действие.
* **Перетаскивание одним пальцем** — панорамирование.
* **Пинч двумя пальцами** — зум.
* Экранные кнопки внизу и сверху адаптированы под крупные пальцы.

## 🚀 Как запустить

Из-за использования ES-модулей (`import` / `export`) игра **не запустится**, если просто открыть `index.html` двойным кликом (через `file://`). Браузер заблокирует загрузку скриптов.

Вам нужен **локальный HTTP-сервер**:

1. Откройте терминал (командную строку) в папке с игрой.
2. Запустите любой из доступных серверов:
   * Python 3: `python3 -m http.server 8000` (или `python -m http.server 8000`)
   * Node.js: `npx serve .`
   * PHP: `php -S localhost:8000`
3. Откройте в браузере: `http://localhost:8000`

## 🎯 Цель игры

* **Победа:** Накопить бюджет в **$5,000,000,000** (5 миллиардов).
* **Поражение:** Бюджет уходит ниже **−$10,000**, ИЛИ население падает до нуля (после того, как оно было больше нуля).

## 🏙️ Механики и правила

1. **Дороги обязательны.** Любое здание можно поставить только на клетку, которая примыкает к дороге.
2. **Зонирование.** Сначала покрасьте клетку зоной (R, C или I), и только потом ставьте туда соответствующее здание (Дом, Офис, Завод).
3. **Снос.** Возвращает 75% стоимости здания (страховка). Дороги сносятся без возврата средств.
4. **Население.** Приток жителей происходит раз в 10 секунд при наличии домов, дорог и нормального бюджета. Если в городе плохая инфраструктура (мало школ/больниц) или долги — люди уезжают.
5. **Экономика.**
   * Каждый житель приносит $10/сек.
   * Завод и Офис приносят по $100/сек.
   * Школы и больницы стоят денег на содержание каждую секунду.
   * Раз в минуту списываются субсидии жителям (население × $5).
6. **Уровень города.** Зависит от населения (до 10 уровня). Каждый уровень даёт +5% к доходу.

## 🛠️ Архитектура проекта

* `index.html` — разметка Canvas, HUD (верхняя панель), панели инструментов и меню.
* `style.css` — стилизация интерфейса в пиксельном стиле (monospace).
* `main.js` — точка входа: инициализация игры, единый цикл `requestAnimationFrame`, обработка меню.
* `Game.js` — ядро игры: состояние карты, экономика, рост населения, проверка победы/поражения.
* `Player.js` — состояние игрока-мэра: камера (зум, панорамирование), текущий выбранный инструмент.
* `input.js` — обработка мыши, тача и клавиатуры, перевод экранных координат в изометрические.
* `collision.js` — логика сетки: проверка, можно ли ставить здание (занятость, соседство с дорогой, зонирование).
* `sound.js` — синтезатор звука на Web Audio API. Генерирует фоновую музыку и звуковые эффекты (клики, стройка, снос) без использования аудиофайлов.
* `README.md` — этот файл.

## 🎨 Графика и Звук (без внешних файлов)

* Вся графика (земля, дороги, здания, дым, флаги, крыши) рисуется кодом через Canvas API в изометрии 2:1. `ctx.imageSmoothingEnabled = false` обеспечивает чёткие пиксели.
* Музыка и звуки синтезируются «на лету» с помощью `OscillatorNode` и `AudioBuffer` (шум). Никаких `.mp3` или `.wav`.
* Рекорд населения сохраняется в `localStorage`.
